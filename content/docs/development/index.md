Every piece of software in Lunar is built from a **module**: a small directory of files in the moonbase that tells Lunar where to download the source, what it depends on and how to build it. These pages explain how modules work, how to write one, and how to get it into the moonbase.

New to modules? Start with [Writing Modules](/docs/development/module-writing), a walkthrough of one real module from start to finish, and keep [Module Basics](/docs/development/module-basics) at hand as the reference.
